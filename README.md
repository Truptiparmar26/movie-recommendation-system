# 🎬 Movie Recommendation System

A content-based Movie Recommendation System built using Python, Machine Learning, NLP, and Flask. The system recommends movies similar to the movie selected by the user based on genres, keywords, overview, cast, and crew.

---

## ✨ Features

- 🎬 Search for a movie
- 🤖 Content-Based Movie Recommendations
- 🧠 Machine Learning and NLP-based approach
- 🎭 Uses genres, keywords, cast, crew, and overview
- ⚡ Fast movie recommendations
- 🌐 Flask REST API
- 🎨 Attractive and user-friendly interface
- 📱 Responsive UI
